# FSAD WebAssembly (WASM)

## Overview

This project demonstrates the use of **WebAssembly (WASM)** and its integration with web technologies.

## Objectives

- Understand the fundamentals of WebAssembly.
- Explore how WASM integrates with web technologies.
- Implement and test WebAssembly functionality.

## Technologies Used

- WebAssembly (WASM)
- Web technologies and tools used in the implementation

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/ishika-sancheti/FSAD-wasm.git
cd FSAD-wasm
```

### Run the Project

Follow the setup instructions applicable to the source files included in the repository.

## Project Structure

The repository contains the implementation files and resources for the WebAssembly project.

## Learning Outcomes

- Understanding WebAssembly and its role in web development.
- Exploring the interaction between WebAssembly and web applications.
- Gaining practical experience through implementation.


This project was created for educational purposes as part of FSAD coursework.
